# Python Fundamentals Project

 
## Overview

This project was completed as part of a Data Technician Bootcamp and demonstrates the application of core Python programming concepts to solve problems, perform calculations, and create interactive user experiences. The exercises focused on building a strong foundation in programming logic and computational thinking through practical tasks and challenges.


## Skills Demonstrated


### Variables and Data Types

- Created and managed variables to store and manipulate data.

- Worked with different data types including integers, floats, and strings.
  
- Applied type casting techniques to convert data between types for calculations and user input processing.
  

### User Interaction

- Utilised `print()` statements to display information and results clearly.

- Used `input()` functions to collect user data and create interactive programs.
  
- Built user-friendly applications that respond dynamically to user choices. 
  
 
### Conditional Logic

- Implemented `if`, `elif`, and `else` statements to control program flow.

- Created decision-making processes for tasks such as number validation, odd/even checks, leap year calculations, and ATM-style menu systems. 
  

### Loops and Iteration

- Applied `for` loops to repeat actions efficiently and process sequences of data.

- Used `while` loops to create menu-driven programs and maintain user interaction until exit conditions were met.
  
- Developed solutions such as the FizzBuzz challenge and number-processing exercises. 
  

### Calculations and Problem Solving

- Created programs to calculate:

- Sums of numbers
  
- Temperature conversions
  
- Rectangle areas
  
- Compound interest
  
- Date and time conversions
  
- Applied mathematical operators and logical reasoning to solve real-world problems. 
  
 
## Key Learning Outcomes

Through these projects, I developed an understanding of:

- Programming fundamentals and Python syntax.

- Writing logical and maintainable code.
  
- Using conditional statements and loops to automate tasks.
  
- Handling user input and validating data.
  
- Building interactive command-line applications.
  

## Example Projects

- FizzBuzz Challenge

- ATM Simulation Program

- Even/Odd Number Checker
  
- Leap Year Validator
